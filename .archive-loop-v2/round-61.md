### Issue #3-4: DeepSeek-R1 example conflates RL with distillation

**Claim in main.tex (L325-326):**
> "DeepSeek-R1, for instance, first selects Group Relative Policy Optimization as its objective, then uses cold-start data from DeepSeek-V3 as its signal source, and finally tunes batch size, learning-rate decay, and sampling temperature to stabilize training dynamics."

**PDF evidence (2501.12948.pdf):**

1. **DeepSeek-R1 主模型训练** (Section 3, Figure 2): multi-stage RL pipeline:
   - Stage 1: Cold-start SFT (thousands of long-CoT data → fine-tune V3-Base)
   - Stage 2: RL with GRPO (rule-based reward for reasoning)
   - Stage 3: Rejection sampling + SFT (reasoning + non-reasoning data)
   - Stage 4: Secondary RL (helpfulness + harmlessness)
   
   **这是 RL 训练，不是 distillation。** GRPO 是 R1 的 RL objective，不是蒸馏 objective。

2. **DeepSeek-R1 蒸馏小模型** (Section B.4.3, Table 6):
   - 方法: SFT fine-tuning on 800K samples generated by R1
   - Base models: Qwen2.5-Math-1.5B/7B, Qwen2.5-14B/32B, Llama-3.1-8B, Llama-3.3-70B
   - 训练: 2-3 epochs, cosine LR decay, batch=64, max_len=32768
   
   **这才是 distillation，但 objective 是 cross-entropy (SFT)，不是 GRPO。**

3. **"Cold-start data"** 的真实含义 (Page 6 + Appendix B.3.2):
   - "thousands of cold-start data that exhibits a conversational, human-aligned thinking process"
   - 目的: bootstrap RL training (overcome incoherence), 不是蒸馏的 signal source
   - 来源: DeepSeek 工程师手工构造 + heuristics (first-person perspective CoT)
   - 不是 "from DeepSeek-V3"——是人工构造的，V3-Base 是被 fine-tune 的底座

**Verdict: ❌ CONFIRMED FACTUAL ERROR**

当前文本把 R1 主模型的 RL 训练（GRPO + cold-start）错误地描述为蒸馏的三阶段示例：
- GRPO 是 RL objective → 不等于 "distillation objective"
- Cold-start data 是 RL warm-up → 不等于 "signal source for distillation"
- R1 的蒸馏实际上用的是 cross-entropy SFT on 800K teacher-generated data

**推荐修复**: 用 GKD 替换 R1 作为 pipeline 示例（GKD 本身就是 on-policy distillation，且覆盖三阶段：Forward KL/JSD objective + teacher logit supervision + interpolated sampling for stability）

### Issue #8: "Forward KL requires access to full output distribution"

**Claim (L328):**
> "Forward KL in its exact token-level form requires access to the teacher's full output distribution"

**Mathematical verification:**
Forward KL at token level: $D_{KL}(p_T || p_S) = \sum_v p_T(v) \log \frac{p_T(v)}{p_S(v)}$

This requires:
- $p_T(v)$ for ALL tokens $v$ in vocabulary → needs teacher's full softmax output
- $p_S(v)$ — available since we own the student

**GKD paper (2306.13649) Section 3 confirms**: GKD equation (2) defines token-level divergence using $p_T(\cdot|y_{<n}, x)$ and $p_S(\cdot|y_{<n}, x)$ — requires teacher distribution. The paper's key contribution is showing this can be computed on student-generated sequences (on-policy).

**Verdict: ✅ CORRECT (mathematically self-evident)**

No cite needed — this is definitional from the formula. But current phrasing "in its exact token-level form" is good because it correctly qualifies that sequence-level approximations (e.g., ranking losses) can work without full distribution.
